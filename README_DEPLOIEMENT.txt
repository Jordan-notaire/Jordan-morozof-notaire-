Pour publier sur GitHub Pages :
1. Dézippez ce dossier.
2. Ouvrez le dossier dézippé.
3. Déposez tout son contenu à la racine du dépôt GitHub : les fichiers .html, le dossier css, le dossier images et le dossier js.
4. Vérifiez que index.html est bien à la racine du dépôt.
5. Ne déposez pas le ZIP directement : GitHub Pages lit les fichiers décompressés.
